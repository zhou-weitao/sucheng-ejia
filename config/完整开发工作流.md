# 苏城e教 - 完整开发工作流

## 📋 项目概述
**项目名称**: 苏城e教 - 苏州家教匹配平台

## 📐 数据库设计规范

### 集合命名：PascalCase
- ✅ `Users`, `Requirements`, `Tutor_Profiles`
- ❌ `users`, `requirements`, `tutors`

### 字段命名：camelCase
```javascript
// Users 表结构
{
  _id: ObjectId,
  openid: String,
  nickName: String,
  avatarUrl: String,
  role: String,        // 'parent' | 'tutor' | ''
  phone: String,
  realName: String,
  idCardVerified: Number, // 0未认证/1审核中/2已认证
  isVip: Boolean,
  createTime: Date,
  updateTime: Date
}

// Requirements 表结构
{
  _id: ObjectId,
  parentId: String,     // 外键 -> Users._id
  parentName: String,
  childGrade: String,
  district: String,
  subjects: Array,      // ['数学', '英语']
  timeAvailability: String,
  budgetRange: String,
  description: String,
  status: String,       // 'open' | 'matched' | 'closed'
  matchedTutors: Array,
  createTime: Date,
  updateTime: Date
}

// Tutor_Profiles 表结构
{
  _id: ObjectId,
  userId: String,       // 外键 -> Users._id
  realName: String,
  phone: String,
  wechat: String,
  school: String,
  grade: String,
  subjects: Array,
  district: String,
  hourlyRate: String,
  selfIntro: String,
  verifyStatus: Number, // 0未认证/1审核中/2已认证
  averageRating: Number,
  createTime: Date,
  updateTime: Date
}
```

## 🔌 云函数接口约定

### 通用返回格式
```javascript
{
  success: Boolean,      // 必须！前端判断依据
  message: String,       // 友好提示信息
  data: Object,          // 返回数据
  error: String          // 错误详情（可选）
}
```

### 云函数清单

| 函数名 | 入参 | 出参 | 说明 |
|--------|------|------|------|
| `login` | userInfo | {user, openid, isNewUser} | 微信登录 |
| `publishRequirement` | parentId, parentName, childGrade... | {requirementId} | 发布需求 |
| `matchTutors` | parentId / tutorId | {matchedTutors, alternativeTutors} | 智能匹配 |
| `updateUserProfile` | userId, updateData | {updated} | 更新资料 |
| `initDB` | 无 | {details} | 初始化空集合 |

## 📝 代码规范

### 1. 错误处理必备
```javascript
// ❌ 错误写法（吞异常）
try { await callFunction() } 
catch (e) {}

// ✅ 正确写法
try {
  await wx.cloud.callFunction({...})
} catch (err) {
  console.error('XXX失败:', err)
  wx.showToast({ title: 'XXX失败', icon: 'none' })
}
```

### 2. 存储数据同步
```javascript
// 任何云端数据变更后，必须同步本地
await wx.cloud.callFunction({ name: 'updateUserProfile', ... })
const userInfo = wx.getStorageSync('userInfo')
wx.setStorageSync('userInfo', { ...userInfo, ...newData })
```

### 3. 加载状态
```javascript
// 所有异步操作必须有loading反馈
wx.showLoading({ title: '加载中...' })
try {
  await ...
} finally {
  wx.hideLoading()
}
```
