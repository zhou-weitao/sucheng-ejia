# 🗄️ 数据库集合设计

## 微信云开发数据库

### 集合列表

| 集合名 | 说明 | 预估数据量 | 索引字段 |
|--------|------|----------|---------|
| Users | 用户表 | 10万+ | openid, role |
| Tutor_Profiles | 家教资料表 | 1万+ | tutor_openid, subjects, district, grade |
| Requirements | 家长需求表 | 5万+ | parent_openid, subject, district, grade |
| Reviews | 评价表 | 10万+ | tutor_id, parent_id |
| Orders | 订单表 | 1万+ | user_id, status |

---

## 1. Users 集合（用户表）

### 字段定义

```json
{
  "_id": "自动生成ID",
  "openid": "微信openid（唯一索引）",
  "role": "角色：tutor / parent",
  "nickName": "昵称",
  "avatarUrl": "头像URL",
  "phone": "手机号",
  "realName": "真实姓名",
  "idCardVerified": "实名认证状态：0未认证/1审核中/2已认证",
  "isVip": "是否VIP会员：true/false",
  "vipExpireTime": "VIP到期时间",
  "createTime": "创建时间戳",
  "updateTime": "更新时间戳"
}
```

### 索引配置
- `openid - 唯一索引（登录查询）
- `role` - 普通索引（按角色筛选）

## 3. Requirements 集合（家长需求表）

### 字段定义

```json
{
  "_id": "自动生成ID",
  "parent_openid": "家长openid（关联Users）",
  "subject": "辅导科目",
  "grade": "孩子年级：小一/.../高三",
  "district": "所在区域",
  "budgetMin": "预算最低时薪（元）",
  "budgetMax": "预算最高时薪（元）",
  "studentGender": "学生性别：male/female/any",
  "tutorGenderPref": "家教性别偏好：male/female/any",
  "availableTime": ["期望上课时间"],
  "description": "补充说明",
  "status": "需求状态：active已发布/matched已匹配/closed已关闭",
  "location": {
    "latitude": "纬度",
    "longitude": "经度"
  },
  "matchedTutors": [{
    "tutorId": "匹配的家教ID",
    "matchScore": "匹配度分数",
    "contacted": "是否已联系：true/false",
```
