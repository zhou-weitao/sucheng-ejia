## 👨‍👩‍👧 家长用户相关

### US-001: 家长发布家教需求
| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 5 |
| **依赖** | 用户注册登录 |

**用户故事**：
> 作为一个家长用户，我想要发布我的家教需求，以便能够匹配合适的家教老师。

**验收标准（Given-When-Then）**：

```
场景1：正常发布需求
Given 家长用户已登录并完成实名认证
When 家长填写科目、年级、区域、预算、期望时间等信息并提交
Then 系统验证必填项，保存需求信息，并自动开始匹配家教

场景2：必填项校验
Given 家长正在填写需求表单
When 家长未填写科目就点击提交
Then 系统提示"请选择辅导科目"，并阻止提交

场景3：发布成功反馈
Given 家长填写完所有必填项并提交
When 提交成功
Then 系统显示"发布成功"，并跳转到匹配结果页面，同时告知"已为您匹配到X位家教"
```

### US-002: 家长浏览匹配的家教列表
| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 3 |
| **依赖** | US-001 |

**用户故事**：
> 作为一个家长用户，我想要查看系统为我匹配的家教老师列表，以便我可以选择最合适的家教。

**验收标准**：

```
场景1：查看匹配列表
Given 家长已发布家教需求
When 家长进入匹配结果页面
Then 系统按匹配度从高到低展示家教列表，每个卡片显示：头像、姓名、科目、教龄、评分、距离、匹配度百分比

场景2：无匹配结果
Given 家长发布的需求没有符合条件的家教
When 查看匹配结果
Then 系统显示"暂无合适的家教"，并建议"扩大搜索范围"或"稍后再来查看"

场景3：匹配度说明
Given 家长查看匹配列表
When 点击"匹配度"标签
Then 弹出匹配度计算说明：科目匹配50% + 区域匹配30% + 年级匹配20%
```

## 🔧 系统功能相关

### US-006: 智能匹配算法
| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 8 |
| **依赖** | US-001, US-004 |

**用户故事**：
> 作为系统管理员，我希望系统能够根据科目、区域、年级等因素自动计算匹配度，以便为家长和家教提供精准的匹配推荐。

**验收标准**：

```
场景1：匹配度计算
Given 系统中有家教A（教数学，园区，可教初一）和家长需求B（找数学，园区，初一）
When 运行匹配算法
Then 匹配度计算为：科目50分 + 区域30分 + 年级20分 = 100分

场景2：部分匹配
Given 家教A（教数学，园区，可教初一）和家长需求C（找数学，吴中区，初一）
When 运行匹配算法
Then 匹配度：科目50 + 区域0（不匹配） + 年级20 = 70分

场景3：多维度加权
Given 需求和家教在多个维度有部分匹配
When 计算匹配度
Then 权重严格按照：科目50% > 区域30% > 年级20%执行

场景4：距离加分机制
Given 家教和家长在同一区域且距离小于2公里
When 计算匹配度
Then 额外加5分距离分（总分不超过100）
```

### US-007: 筛选和排序功能
| 字段 | 内容 |
|------|------|
| **优先级** | P1 |
| **故事点** | 3 |
| **依赖** | US-002 |

**用户故事**：
> 作为一个家长用户，我想要按照科目、价格、距离等条件筛选家教，以便找到最符合我要求的老师。

**验收标准**：

```
场景1：按科目筛选
Given 家长在匹配列表页
When 选择"数学"科目筛选
Then 只显示教授数学的家教

场景2：按价格区间筛选
Given 家长选择价格区间"50-100元/小时"
When 应用筛选
Then 列表只显示时薪在该区间的家教

场景3：按距离排序
Given 家长点击"距离最近"排序
Then 列表按照与家长的直线距离从近到远排序

场景4：综合排序（默认）
Given 家长未选择特定排序方式
When 查看列表
Then 默认按匹配度从高到低排序
```
