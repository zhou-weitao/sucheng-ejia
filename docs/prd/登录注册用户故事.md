## US-AUTH-001: 微信快捷登录

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 3 |
| **依赖** | 无 |

**用户故事**：
> 作为一个新用户，我想要通过微信一键登录，以便快速开始使用小程序，不需要手动注册账号。

**验收标准（Given-When-Then）**：

```
场景1：首次登录
Given 用户第一次打开小程序
When 点击"微信快捷登录"按钮
Then 弹出微信授权弹窗，用户确认后系统自动获取用户信息（昵称、头像），创建账号并登录成功

场景2：已有账号登录
Given 用户之前已经登录过
When 再次打开小程序
Then 系统自动检测本地缓存的openid，直接自动登录，无需再次授权

场景3：登录失败处理
Given 用户点击登录按钮
When 网络异常或微信接口调用失败
Then 显示"登录失败，请重试"提示，3秒后自动重试或提供手动重试按钮
```

**开发任务分解（3故事点）**：
- [ ] 前端：登录页面UI（logo + 登录按钮）（0.5点）
- [ ] 前端：wx.login获取code（0.5点）
- [ ] 云函数：login - 通过code换取openid（1点）
- [ ] 前端：wx.getUserProfile获取用户信息（0.5点）
- [ ] 前端：登录状态本地存储持久化（0.5点）

## US-AUTH-002: 选择用户角色

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 2 |
| **依赖** | US-AUTH-001 |

**用户故事**：
> 作为一个新用户，我想要在首次登录后选择我的身份角色（家教/家长），以便系统为我展示对应的功能界面。

**验收标准**：

```
场景1：首次登录选择角色
Given 用户首次登录成功
When 进入角色选择页面
Then 显示两个大卡片："我是家教"和"我是家长"，点击任一选项后保存角色并进入对应首页

场景2：角色选择持久化
Given 用户已选择角色
When 下次打开小程序
Then 直接进入对应角色的首页，不再显示角色选择页面

场景3：修改角色（后续迭代）
Given 用户已选择角色
When 在个人中心点击"切换角色"
Then 可以切换到另一角色，数据互不干扰
```

**开发任务分解（2故事点）**：
- [ ] 前端：角色选择页面UI（两个大卡片）（1点）
- [ ] 前端：保存角色到Users集合 + 本地存储（0.5点）
- [ ] 前端：根据角色跳转对应首页（0.5点）

## US-AUTH-003: 家长完善资料

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 2 |
| **依赖** | US-AUTH-002 |

**用户故事**：
> 作为家长用户，我想要在选择角色后完善我的基本资料，以便发布家教需求。

**验收标准**：

```
场景1：完善基本资料
Given 家长选择角色后
When 进入资料完善页面
Then 填写：称呼（如"王女士"）、手机号、孩子年级、所在区域

场景2：手机号验证
Given 家长填写手机号
When 输入11位数字
Then 实时验证格式，格式错误时显示"请输入正确的手机号"

场景3：跳过完善（可选）
Given 家长不想立即完善资料
When 点击"稍后完善"按钮
Then 可以直接进入首页，但发布需求时提示完善资料
```

**开发任务分解（2故事点）**：
- [ ] 前端：家长资料完善页面UI（1点）
- [ ] 前端：表单验证和提交（0.5点）
- [ ] 云函数：更新用户资料（0.5点）

## US-AUTH-004: 家教完善资料

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **故事点** | 5 |
| **依赖** | US-AUTH-002 |

**用户故事**：
> 作为家教用户，我想要在选择角色后完善我的教学资料，以便被家长搜索和匹配。

**验收标准**：

```
场景1：填写基本教学信息
Given 家教选择角色后
When 进入资料完善页面
Then 填写：真实姓名、性别、年龄、学历、毕业院校、专业、教龄、时薪范围

场景2：选择可教授科目
Given 家教正在完善资料
When 点击科目选择
Then 弹出多选科目列表，可选择1-N个教授科目

场景3：选择可授课年级
Given 家教正在完善资料
When 点击年级选择
Then 弹出多选年级列表，可选择可教授的年级范围

场景4：选择可授课区域
Given 家教正在完善资料
When 点击区域选择
Then 弹出苏州各区县选项，可多选

场景5：选择可授课时间
Given 家教正在完善资料
When 点击可授课时间
Then 按周一到周日，分为上午/下午/晚上，可多选时间段

场景6：上传头像和学历证明
Given 家教正在完善资料
When 点击上传头像或学历证明
Then 调用微信图片选择器，上传成功后显示预览
```

**开发任务分解（5故事点）**：
- [ ] 前端：家教资料完善页面UI（多步骤表单）（2点）
- [ ] 前端：科目/年级/区域/时间多选器组件（1点）
- [ ] 前端：图片上传到云存储（1点）
- [ ] 云函数：保存家教资料到Tutor_Profiles集合（1点）
