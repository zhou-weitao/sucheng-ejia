## 2. 视觉系统升级 - Design Tokens v2.0

### 2.1 新增 Token

```css
/* 背景系统升级 */
--bg-gradient: linear-gradient(135deg, #f5f7fa 0%, #e4e8f0 100%);
--bg-card-glass: rgba(255, 255, 255, 0.85);
--bg-card-blur: blur(20rpx);

/* 边框升级 */
--border-light: 1px solid rgba(255, 255, 255, 0.5);
--border-shadow: 0 8rpx 32rpx rgba(102, 126, 234, 0.1);

/* 动画曲线 */
--ease-out: cubic-bezier(0.4, 0, 0.2, 1);
--animation-fast: 0.2s var(--ease-out);
--animation-normal: 0.3s var(--ease-out);

/* 点击热区 */
--touch-min-size: 48rpx;

/* 状态样式 */
--state-hover: translateY(-2rpx);
--state-active: translateY(2rpx);
```

### 2.2 核心视觉升级点
1. **页面背景**：从纯色改为浅渐变背景
2. **卡片样式**：统一为玻璃拟态风格（半透明 + 模糊 + 内阴影）
3. **交互反馈**：所有可点击元素增加状态动画
4. **点击热区**：统一 48rpx 最小点击区域
5. **阴影系统**：3层阴影层次，形成空间感

## 3. 分页面详细设计

### 🏠 页面1：首页列表 (index)

#### 3.1.1 搜索栏优化
**当前问题**：普通输入框，无视觉层次

**优化方案**：
```
┌─────────────────────────────────────────┐
│  🔍  搜索科目、大学、区域...            │  ← 玻璃拟态搜索栏
└─────────────────────────────────────────┘
```
- 背景：半透明白色 + 模糊 + 圆角 24rpx
- 左右内边距：32rpx
- 搜索图标左对齐，占位文字灰色
- 聚焦时：边框高亮 + 阴影放大动画

#### 3.1.2 筛选栏优化
**优化方案**：胶囊筛选器
```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ 科目 ▼│ │ 年级 ▼│ │ 价格 ▼│ │ 区域 ▼│  ← 胶囊式按钮
└──────┘ └──────┘ └──────┘ └──────┘
```
- 每个筛选器：胶囊按钮样式，圆角 20rpx
- 选中状态：渐变背景 + 白色文字
- 未选中：白底 + 灰色文字 + 细边框
- 点击时：缩放 + 颜色过渡动画

#### 3.1.3 列表卡片优化
**当前问题**：信息密度高但层级不清晰，匹配标签不突出

**优化方案**：
```
┌─────────────────────────────────────────────┐
│ ┌─┐                                       │
│ │🅰│  张老师  ✅ 已认证               95% 🎯│  ← 匹配度角标
│ └─┘  🏫 苏州大学  📚 数学  🎓 高一        │
│      💬 ⭐⭐⭐⭐☆ (12条评价)            │
│      📍 姑苏区                             │
│ ───────────────────────────────────────── │
│    ¥120 /小时                            →│  ← 价格右对齐
└─────────────────────────────────────────────┘
```

**关键改动**：
1. **头像升级**：大尺寸 80rpx + 渐变色背景 + 首字母
2. **认证徽章**：绿色背景 + 白色对勾图标 + 圆角
3. **匹配度角标**：右上角渐变背景 + 百分比
4. **评分可视化**：金色五角星 + 评价数量括号显示
5. **标签统一**：使用 emoji 图标前缀 + 文字
6. **底部价格**：加粗 + 深色 + 右对齐

**交互动画**：
- 点击：卡片向上偏移 4rpx + 阴影放大
- 释放：回弹效果
- 首次进入：列表项逐个淡入上滑

#### 3.1.4 空状态优化
```
      📭
  暂无匹配结果

  调整筛选条件试试
```
- 图标：120rpx 大号 + 透明度 0.3
- 主文案：32rpx 加粗 + 中灰色
- 副文案：24rpx + 浅灰色 + 居中

## 4. 通用组件规范

### 4.1 按钮系统

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| **主按钮** | 紫色渐变 + 白色文字 + 阴影 | 登录、提交、解锁 |
| **次按钮** | 白底 + 紫色边框 + 紫色文字 | 取消、返回 |
| **幽灵按钮** | 透明 + 紫色边框 | 次要操作 |
| **禁用状态** | 灰色背景 + 50% 透明度 | 表单未完成 |

### 4.2 标签系统

| 类型 | 样式 | 示例 |
|------|------|------|
| **成功标签** | 绿色背景 + 白色文字 | 已认证 |
| **警告标签** | 橙色背景 + 白色文字 | 审核中 |
| **信息标签** | 蓝色背景 + 白色文字 | 匹配 |
| **红色标签** | 红色背景 + 白色文字 | 去认证 |

### 4.3 阴影系统

| 层级 | 阴影值 | 使用场景 |
|------|--------|----------|
| L1 | `0 2rpx 8rpx rgba(0,0,0,0.04)` | 输入框、小标签 |
| L2 | `0 4rpx 24rpx rgba(0,0,0,0.06)` | 普通卡片 |
| L3 | `0 8rpx 32rpx rgba(102,126,234,0.15)` | 悬浮卡片、按钮 |
