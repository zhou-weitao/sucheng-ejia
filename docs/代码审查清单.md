# 🔍 代码审查清单

## 审查级别定义
- **Blocker** - 必须修改，否则不能合并
- **Critical** - 严重问题，建议修改
- **Major** - 重要问题，需要讨论
- **Minor** - 小问题，建议优化
- **Info** - 提示信息，可选修改

---

## 📋 通用审查项

### 1. 正确性（Blocker级别）
- [ ] 无语法错误，可正常运行
- [ ] 无明显的逻辑错误
- [ ] 边界条件处理正确（空值、异常情况）
- [ ] 异步操作有错误处理

### 2. 安全性（Blocker级别）
- [ ] 无敏感信息硬编码（AppID、密钥等）
- [ ] 用户输入有验证和过滤
- [ ] 云函数权限设置合理
- [ ] 数据库操作有安全校验

### 3. 性能（Critical级别）
- [ ] 无明显的性能问题
- [ ] 循环嵌套不超过3层
- [ ] 数据库查询有合适的索引
- [ ] 图片资源大小合理（<200KB）

---

## 💻 前端代码审查项

### WXML/WXSS
- [ ] WXML标签闭合正确
- [ ] 没有使用不支持的HTML标签
- [ ] 类名命名有意义，使用BEM或类似规范
- [ ] 颜色值统一使用变量（#2B8CFF等）
- [ ] 没有多余的嵌套选择器

### JavaScript
- [ ] 未在WXML中调用复杂JS方法（已在data中预处理）
- [ ] wx.setStorageSync / getStorageSync使用正确
- [ ] 页面onLoad/onShow/onHide生命周期合理使用
- [ ] 事件处理函数命名清晰（handleXXX）
- [ ] 无魔法数字，使用常量定义
- [ ] 重复代码已抽取为公共方法

### 组件化
- [ ] 可复用的UI已封装为组件
- [ ] 组件props定义清晰，有默认值
- [ ] 组件之间通信使用events/observers正确

---

## ☁️ 云函数代码审查项

### 正确性
- [ ] wx-server-sdk已正确初始化
- [ ] cloud.getWXContext()使用正确
- [ ] 数据库操作有catch错误处理
- [ ] async/await使用正确，无不处理的Promise

### 性能
- [ ] 数据库查询使用limit限制返回数量
- [ ] 查询字段使用field只取需要的字段
- [ ] 避免在循环中进行数据库操作

### 安全
- [ ] 有用户权限校验（需要时）
- [ ] 传入参数有校验和过滤
- [ ] 返回结果不包含敏感信息

---

## 📝 代码风格

- [ ] 缩进统一为2空格
- [ ] 使用单引号字符串
- [ ] 语句结尾有分号
- [ ] 变量命名有意义（不使用a/b/c/xx1）
- [ ] 函数名使用动词开头（get/set/handle/calc）
- [ ] 无注释掉的大段代码
- [ ] 复杂逻辑有注释说明

---

## ✅ 合并条件

代码可以合并当且仅当：
1. 没有Blocker级别的问题
2. Critical级别问题已讨论并有结论
3. 所有审查意见已回应或已修复
4. 功能自测通过
5. 相关文档已更新
